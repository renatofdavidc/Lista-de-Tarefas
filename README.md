# Lista de tarefas

Projeto simples de uma lista de tarefas, desenvolvido com HTML, CSS, JavaScript e PHP.
O programa permite o usuário criar, editar, visualizar, concluir e excluir tarefas de sua lista, que fica salva em um arquivo JSON.
Minha primeira vez usando PHP, ainda não entendo tudo plenamente, mas pude fazer funcionar.

Para rodar:
- Clonar o repositório;
- Instalar o XAMPP (se ainda não tiver instalado)
- Adicionar a pasta do projeto à pasta htdocs do XAMPP;
- Acessar http://localhost/ListaTarefas/ no navegador, com o servidor XAMPP incializado;
- Testar as funcionalidades.
